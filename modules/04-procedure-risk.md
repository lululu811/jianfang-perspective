# 04-procedure-risk.md: 交易程序、仓位管理与风控体系

> **加载条件**: 询问交易流程、仓位控制、风险管理时加载

## 七步交易程序

1. **识别动量主线** —— 当下最强板块是什么？
2. **筛选最强逻辑** —— 大风口/强逻辑/好赛道/超业绩？
3. **分析走势结构** —— 处于四阶段中的哪个阶段？
4. **等待买点信号** —— 突破/中继/反转，哪类买点出现？
5. **设定止损位** —— 买入前先想好退出方案
6. **执行买入** —— 按信号操作，不让主观想法干扰
7. **持仓管理** —— 跟踪趋势，按卖点信号离场

### 波段轮动操作SOP（股池更新中每期重复）

```
步骤1：回避下降趋势 → 股池里出现下降趋势的不碰
步骤2：如果股池里所有股都变成下降趋势 → 市场非常差 → 只能休息
步骤3：买点 → 只在衰竭点低吸，不追涨
步骤4：止盈点 → 加速一律止盈
步骤5：止损点 → 买入前设好，没有止损不要买任何一只个股
    ├─ 买突破的 → 突破失败止损
    ├─ 买衰竭的 → 衰竭失败止损
    ├─ 买恐慌的 → 恐慌失败止损
    └─ 买底部反转的 → 反转失败止损
```

"因为我们是波段轮动策略，不是死拿。"

## 仓位管理

- **操作单位**: 5%为基本单位
- **分散度**: 4-5只个股，分散到3+个行业
- **核心原则**: "平时常空仓，到位重出击"

### 仓位控制双原则（量价原理课独有）
1. **让信号引导仓位**: 有信号就交易，没信号就控仓等待——"如此下来，根本没有必要考虑应该保留多少仓位的问题"
2. **让胜率引导仓位**: 胜率是最好的温度计——经常止损→降低仓位、减少频率→"适度休息一下，往往都会有好的改善"

### 四个概率组合
```
概率高+仓位高 = 盈利高  ← 追求
概率高+仓位低 = 盈利低  ← 避免（不敢重仓）
概率低+仓位低 = 亏损低  ← 防御
概率低+仓位高 = 亏损高  ← 绝对避免
```

## 五道风控防线

| 防线 | 内容 | 作用 |
|------|------|------|
| ① 概率层面 | 识别概率优势，只在有优势时参与 | 过滤无效机会 |
| ② 买点层面 | 关键点买入，不追加速不抄底 | 控制入场质量 |
| ③ 止损层面 | 每笔交易预设止损，触发即执行 | 限制单笔损失 |
| ④ 仓位层面 | 动态调整，分仓分散 | 控制总体风险 |
| ⑤ 回撤控制 | 整体回撤达到阈值全面减仓 | 防止系统性风险 |

"交易的第一目标是生存——控制回撤，复利才能长久。"

---

## 体系固有局限（简放自承认）

- **震荡市反复止损**: 趋势策略最怕小幅震荡，产生大量虚假信号
- **动量崩塌风险**: 行情急转直下时体系失效
- **"最终会错一次"**: 承认这种模式必然犯错
- **滞后性**: 依据历史价格惯性，拐点处难以及时反应
