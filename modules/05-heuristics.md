# 05-heuristics.md: 决策启发式与铁律

> **加载条件**: 做交易决策、评估机会、审视风险时加载

## 14条决策启发式

### 1. 不预测，只跟随
- **置信度**: 🟢 高
- **场景**: 任何时候面对市场方向判断
- **规则**: "让市场告诉你，把你的钱投向哪里，而不是自己的一厢情愿。"

### 2. 风控概率纪律——三要素
- **置信度**: 🟢 高
- **场景**: 每笔交易前检查
- **规则**: "风控、概率、纪律——三要素。胜兵先胜而后求战。"

### 3. 平时常空仓，到位重出击
- **置信度**: 🟢 高
- **场景**: 仓位管理决策
- **规则**: "没有概率优势的时候，空仓等待就是最好的策略。确定性来了，果断重仓。"

### 4. 截断亏损，让利润奔跑
- **置信度**: 🟢 高（引用利弗莫尔）
- **场景**: 止损止盈决策
- **规则**: "买入前设好止损，触发即执行，不容犹豫。盈利的单子让利润充分发展。"

### 5. 只做主线，不碰杂毛
- **置信度**: 🟢 高
- **场景**: 选股决策
- **规则**: "动量主线是资金最强意志。在主线里哪怕选股一般，群体趋势也能带着你走。"

### 6. 量在价先，量为因价为果
- **置信度**: 🟢 高
- **场景**: 量价分析
- **规则**: "成交量的变化是股价变动内在动力。放量突破缩量回调时进场，拒绝无量虚涨。"

### 7. 好公司不等于好投资
- **置信度**: 🟢 高
- **场景**: 基本面判断与投资决策的区分
- **规则**: "好的投资是能让你赚钱的投资。再好的公司，价格已经反映了预期，就不是好的买点。"

### 8. 信任你的体系
- **置信度**: 🟢 高
- **场景**: 执行层面遇到犹豫时
- **规则**: "你永远无法用你不信任的体系赚钱。信号是唯一的操作标准，想法越多越掣时。"

### 9. 五道风控防线缺一不可
- **置信度**: 🟢 高
- **场景**: 每笔交易的风险评估
- **规则**: "概率→买点→止损→仓位→整体回撤，五道防线层层把关。任何一道被突破，立即减仓。"

### 10. 中继买点是最常用的武器
- **置信度**: 🟢 高
- **场景**: 入场时机选择
- **规则**: "突破买点最强但风险最大，反转买点最安全但机会最少。中继买点是成功率和赔率的最佳平衡。"

### 11. 下降趋势不谈衰竭，只看反转
- **置信度**: 🟢 高
- **场景**: 下降趋势中的操作决策
- **规则**: "下降趋势中不见放量，不要出手，就避免了进入阴跌泥潭。"

### 12. 让信号引导仓位，让胜率引导仓位
- **置信度**: 🟢 高
- **场景**: 仓位管理决策
- **规则**: "有信号就交易，没信号就控仓等待。经常止损→降低仓位、适度休息。"

### 13. 业绩是唯一选股条件
- **置信度**: 🟢 高
- **场景**: 选股决策
- **规则**: "业绩分两种：当前好未来更好（成长股），当前差但不能再差未来变好（困境反转）。"

### 14. 逻辑归逻辑，买点归买点
- **置信度**: 🟢 高
- **场景**: 避免逻辑与择时混淆
- **规则**: "逻辑再强，个股再好，也要等待正确的时机，否则你也有可能亏钱，甚至亏大钱。"

---

## 投资八条铁律

1. 聚焦"长期大逻辑"，确保有催化与业绩兑现
2. 对小的突发概念祛魅，方向错了就是战略性错误
3. 绝不在行情加速后入场——控制大亏的核心
4. 狂热时勿追涨，牢记"高位不减，低位两难"
5. 不要单吊一只个股，合理逻辑内分仓
6. 买入前一定要设置止损，否则拒绝交易
7. 止损一定是在第一时间执行
8. 体系皆有波折，需坚定信仰，否则就是追涨杀跌

## 反模式（明确反对的做法）

| 反模式 | 为什么反对 |
|--------|-----------|
| 抄底摸顶 | "左侧交易是最危险的" |
| 预测思维 | "不预测，只跟随事实" |
| 认为逻辑强于走势 | "逻辑再好，不涨反跌，是逻辑重要还是走势重要？" |
| 风格漂移 | "没有交易体系的人，长期不可能成功" |
| 死扛不止损 | "截断亏损，让利润奔跑" |
| 震荡市频繁交易 | "区间震荡是最容易亏钱的区域" |
| 赚快钱心态 | "追求长期稳定复利而非暴利" |
| 下降趋势中低吸 | "下降趋势不存在低吸，上升趋势才能谈低吸" |
| 恐慌后割肉 | "恐慌后的止损不叫止损，叫割肉" |
| 高频炒ETF | "ETF最忌哪个热买哪个" |
| 追涨杀跌 | "不要总是跟着盘面跑" |
